Adds a project-level Cursor subagent (`.cursor/agents/mail-data-ops.md`) for diagnosing Mission Control outbound mail failures and multi-page site-data/stats drift.

- **Mail stack**: cred vault → GitHub `admin-production` → Pages secrets → `MAIL_RELAY` / REST / Resend transport chain
- **Site-data stack**: baked `site-data.json`, `/api/site-data` live cache, KV stats refresh, stats-cron worker
- **Known failure modes**: Workers Free sandbox, unverified Resend domain, skipped `CLOUDFLARE_EMAIL_API_TOKEN` sync when relay exists, push-to-main skipping mail setup

## Investigation context

This subagent was created after tracing mail + data issues where cred vault and GitHub secrets appear set but runtime delivery or dashboard KPIs still fail. It encodes the diagnostic workflow and fix matrix from that analysis.

No runtime code changes — agent configuration only.
