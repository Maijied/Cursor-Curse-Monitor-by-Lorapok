## PR body (excerpt)

Adds a separate, non-deploying workflow and a small Playwright harness that renders the built popup using fake browser APIs. It captures the disconnected popup in English and Bangla at two widths, blocks all requests except the loopback build, and never accesses personal browser profiles, sessions, or screenshots.

The screenshot job has read-only repository access and no Argos credentials. A separate trusted-branch upload job sends only the four allowlisted PNG artifacts using short-lived GitHub OIDC; fork PRs cannot upload. No GitHub secret, branch protection, marketplace publication, or deployment changes.

Local checks: production browser build, script syntax, workflow YAML. The local sandbox denied Chrome’s process socket, so the screenshot run will be verified in GitHub Actions.
