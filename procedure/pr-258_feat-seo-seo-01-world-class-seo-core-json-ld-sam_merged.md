### Firebase deploy fix
The CI step `Deploy Firestore rules` was failing after logging:
`{"serviceAccountEmail":"firebase-adminsdk-fbsvc@...","projectId":"cursor-curse-by-lorapok","source":"env"}`

Root cause: `formatDeployFailure()` matched the benign firebase info line *"checking firestore.rules for compilation errors..."* (because of the word **errors**) and hid the real HTTP/IAM error.

**Fix:** skip info lines, log full firebase CLI output in CI, normalize service-account key file, add `.firebaserc`, safe heredoc for `FIREBASE_SERVICE_ACCOUNT_JSON` in GitHub Actions.
