Local-first product

Cursor Curse Monitor is a VS Code / Cursor extension that runs on your machine. It reads your local Cursor session (auth material and privacy-safe metadata in state.vscdb) only to show your usage in the dashboard. We do not read chat transcripts, message bodies, or project file contents.

Optional anonymous heartbeat

Usage statistics from the extension are off by default (cursorCurseMonitor.anonymousUsageStats). If you enable them, the extension sends at most one ping per UTC day containing:

  • A random install ID stored in extension globalState (created once and never regenerated so offline VSIX and later marketplace installs on the same machine stay unique)
  • Operating system platform, host editor (Cursor or VS Code), and extension version

No email, path, token, workspace name, or Cursor chat content is included.

Marketplace downloads and website visits

Public download counts and marketing-site visit/click totals are separate from the extension heartbeat. They come from marketplace APIs and first-party site counters (and optional Google Analytics only if we configure a measurement ID). These do not require any extension setting.

Database safety

Monitoring reads Cursor’s database in read-only mode while the editor is running. Optional free-fallback model changes write only after Cursor/VS Code is fully quit, with backups of state.vscdb, WAL, and SHM files and integrity checks so your data is not left corrupted.
